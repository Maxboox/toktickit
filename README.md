# TokTickIT

**TokTickIT** is an IT service desk application for managing Account and Access, Hardware, Software, and Network requests.  
This project is built as part of a full-stack development course at KMUTT.

---

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React + TypeScript + Vite + Bootstrap |
| Backend | Node.js + Express + TypeScript |
| Database | PostgreSQL + Prisma ORM |
| Testing | Vitest (frontend) + Supertest (backend) |
| Version Control | Git + GitHub |
